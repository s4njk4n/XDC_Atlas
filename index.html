Add your project

Built something for XDC, or run a service that supports it? List it here so people can find it. Big or small, open source or not.

  1. Copy the template and fill it in.
  2. Open a pull request adding it to data/tools.json in the XDC_Atlas repo. Listings are only accepted by pull request.
  3. Already listed? Put an xdc-tool.json with the same fields in your own repo to claim it.

Add a tipAddress if you'd like a tip button on your card. Tips go straight to you; XDC Atlas never holds funds.

Submit an RPC

Endpoints on this page come from three places: Chainlist, the official XinFin tools guide, and pull requests from people who run their own. If you run a public XDC endpoint, you can add it.

  1. Copy the template and fill it in.
  2. Open a pull request adding it to the right network in data/rpcs.json in the XDC_Atlas repo. Submissions are only accepted by pull request.

Before you submit, check that your endpoint:

  • is public and needs no sign-up or API key,
  • uses https:// or wss:// and returns the right chain ID (50 for mainnet, 51 for Apothem),
  • allows browser requests (CORS), or it will show as unreachable here,
  • has a privacy value that matches how you treat request data: none, limited or yes.

Endpoints that stop answering for a long stretch may be removed.

  "url": "https://your-node.example.com",
